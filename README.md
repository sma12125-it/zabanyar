# زبان‌یار — اپ آموزش انگلیسی محاوره‌ای با رابط فارسی (نسخه‌ی ۳)

اپ وب پیش‌رونده (PWA) + اپ اندروید (APK) برای یادگیری **انگلیسی واقعی و محاوره‌ای** (آمریکایی/بریتانیایی) با روش «اول گفتگو».

- **۱۰۲ سناریوی واقعی** از A1 تا C1 (گفتگو، تکه‌های کلیدی، کتابی در برابر محاوره‌ای، گفتار پیوسته، سایه‌روی، نقش‌آفرینی گفتاری، شنیداری و دیکته)
- **۲۶۱۷ عبارت** با ترجمه‌ی فارسی (۲۰۷۷ در سناریوها + ۵۴۰ عبارت پرکاربرد در برنامه‌ی ۳۰ روزه)
- **برنامه‌ی فشرده‌ی ۳۰ روزه‌ی مکالمه** (هدف: گفتگوی روزمره با اعتمادبه‌نفس — روانی در حد بومی در یک ماه تضمین نمی‌شود)
- **معلم هوش مصنوعی** (Google Gemini، مدل پیش‌فرض `gemini-3.8-flash`) با ۶ حالت آموزشی، آگاه از سطح، درس و کلمات ضعیف شما، خلاصه‌ی پایان جلسه و افزودن اشتباهات به مرور، و **حالت صوتی بدون دست**
- مرور فاصله‌دار، XP و رکورد روزانه، حالت تاریک، کار آفلاین، پشتیبان‌گیری/بازیابی

---

## ۱) ساختار پروژه
| مسیر | توضیح |
|---|---|
| `src/` | کد اپ (HTML/CSS/JS خالص، بدون وابستگی) |
| `content/*.js` و `content-src/*.txt` | منبع محتوا (سناریوها و بسته‌های ۳۰ روزه) |
| `scripts/build.mjs` | ساخت خروجی: اعتبارسنجی محتوا، JSON جدا برای هر سطح، Service Worker نسخه‌دار |
| `dist/` | **خروجی قابل انتشار** (همین را روی هاست بگذارید) |
| `proxy/` | سرور واسط نمونه برای Gemini (Cloudflare Worker و Node) — راهنما: `proxy/README-fa.md` |
| `android-app/` | پروژه‌ی Capacitor برای ساخت APK |
| `docs/` | سند محصول (`concept-fa.md`) و تصاویر |

## ۲) ساخت
```
node scripts/build.mjs        # Node 18 یا بالاتر؛ خروجی در dist/
```
برای افزودن سناریو: یک بلوک به `content-src/<سطح>.txt` اضافه کنید (قالب: `# آیکون|عنوان|موقعیت|نام طرف` سپس خطوط `A|..|..` و `B|..|..` (B = کاربر)، `+ عبارت|ترجمه`، `! کتابی|محاوره‌ای|توضیح`، `~ عبارت|تلفظ|توضیح`) و دوباره build کنید. اسکریپت خطاهای محتوا را گزارش می‌دهد.

اجرای محلی: `cd dist && python3 -m http.server 8000` ← `http://localhost:8000`

## ۳) انتشار روی اینترنت (HTTPS الزامی است)
میکروفون، Service Worker و نصب PWA **فقط روی HTTPS** (یا localhost) کار می‌کنند. محتوای پوشه‌ی `dist/` (یا فایل `zabanyar-web.zip`) را روی هر هاست استاتیک با HTTPS بگذارید:
- **Cloudflare Pages / Netlify:** پوشه‌ی `dist` را آپلود کنید (Drag & Drop). فایل `_headers` قوانین کش را تنظیم می‌کند.
- **GitHub Pages / Vercel:** محتوای `dist` را منتشر کنید.
- **هاست/سرور شخصی (nginx/Apache/Caddy):** فایل‌ها را در ریشه‌ی سایت کپی کنید و گواهی رایگان Let's Encrypt بگیرید. توصیه: برای `sw.js` و `index.html` هدر `Cache-Control: no-cache` بگذارید.
- برای کاربران ایران: هاست داخلی برای خود اپ سریع‌تر است؛ ولی Gemini از ایران مسدود است ← از **سرور واسط خارج از ایران** (پوشه‌ی `proxy/`) استفاده کنید و در اپ: تنظیمات ← «Gemini از طریق سرور واسط».

پس از هر تغییر، دوباره build کنید؛ نسخه‌ی جدید خودکار شناسایی و بنر «به‌روزرسانی» به کاربران نشان داده می‌شود.

## ۴) نصب روی آیفون (PWA)
1. سایت را در **Safari** باز کنید (آدرس https).
2. دکمه‌ی **Share** (مربع با فلش رو به بالا) را بزنید.
3. **Add to Home Screen** ← **Add**.
4. زبان‌یار مثل یک اپ با آیکون و صفحه‌ی شروع، تمام‌صفحه باز می‌شود و آفلاین هم کار می‌کند.
- **میکروفون در آیفون:** اولین بار که 🎤 را می‌زنید، اجازه بدهید. چون Web Speech در iOS محدود است، اپ صدا را ضبط و با Gemini به متن تبدیل می‌کند ← برای تمرین گفتار در آیفون **کلید Gemini یا سرور واسط لازم است**. اگر اجازه را رد کردید: Settings ← Safari ← Microphone (یا اپ را از صفحه حذف و دوباره اضافه کنید).
- پخش صدا (TTS) در آیفون پس از اولین لمس صفحه فعال می‌شود؛ صدای گوشی را از حالت بی‌صدا خارج کنید.

## ۵) نصب روی اندروید
- **روش ساده (PWA):** سایت را در Chrome باز کنید ← منو ⋮ ← **Install app / افزودن به صفحه‌ی اصلی**.
- **فایل APK:** فایل `zabanyar.apk` را به گوشی منتقل کنید ← باز کنید ← اگر خواست، «نصب از منابع ناشناس» را برای مرورگر/مدیر فایل فعال کنید ← Install. هنگام اولین تمرین گفتار، اجازه‌ی میکروفون را بدهید.
  - این APK **نسخه‌ی دیباگ** است (با کلید دیباگ امضا شده) و برای تست/توزیع مستقیم مناسب است، نه Google Play.
  - در اپ اندروید، تشخیص گفتار با سرویس گفتار خود گوشی (گوگل) و پخش صدا با موتور TTS گوشی انجام می‌شود.

### ساخت دوباره‌ی APK
پیش‌نیاز: Node 22+، JDK 21، Android SDK (platform 36). سپس:
```
cd android-app
npm install
npm run apk        # = build وب + cap sync + gradlew assembleDebug
# خروجی: android-app/android/app/build/outputs/apk/debug/app-debug.apk
```
برای انتشار در Google Play: یک keystore بسازید، `assembleRelease` (یا `bundleRelease`) را با امضای خودتان اجرا کنید.

## ۶) تنظیم معلم هوش مصنوعی
1. کلید رایگان از [Google AI Studio](https://aistudio.google.com/apikey) (نیاز به VPN از ایران).
2. اپ ← تنظیمات ← سرویس «Google Gemini» ← کلید ← «آزمایش اتصال».
3. یا (توصیه‌شده برای انتشار عمومی) سرور واسط را طبق `proxy/README-fa.md` راه‌اندازی کنید تا کلید در دست کاربران نباشد.

## ۷) محدودیت‌های شناخته‌شده
- نمره‌ی تلفظ بر اساس مقایسه‌ی کلمات است، نه تحلیل واج‌ها.
- کیفیت صدای TTS به صداهای نصب‌شده روی دستگاه بستگی دارد.
- محتوا توسط سازنده نوشته شده و بازبینی یک گوینده‌ی بومی پیش از انتشار گسترده توصیه می‌شود.
- iOS: نسخه‌ی App Store ساخته نشده (نیاز به مک و حساب توسعه‌دهنده‌ی اپل)؛ PWA جایگزین است.

## 🎤 عیب‌یابی میکروفون («صدایی دریافت نشد»)
از نسخه‌ی ۵، موتور پیش‌فرض گفتار **«پایدار: ضبط صدا + Gemini»** است: خود اپ صدا را با میکروفون ضبط می‌کند (نوار قرمز ضبط با نشانگر سطح صدا در پایین صفحه)، با تشخیص سکوت خودکار متوقف می‌شود و صدا را (به‌صورت WAV ۱۶ کیلوهرتز) برای تبدیل به متن به Gemini یا سرور واسط می‌فرستد.
- علت مشکل قبلی: تشخیص گفتار اندروید و Chrome (Web Speech) صدا را به سرورهای Google می‌فرستند که از ایران مسدود/ناپایدارند؛ میکروفون روشن می‌شد ولی متنی برنمی‌گشت.
- «تشخیص سریع» (گوشی/مرورگر) هنوز در تنظیمات قابل انتخاب است؛ اگر جواب ندهد خودکار به ضبط + Gemini برمی‌گردد و پس از دو خطای پیاپی موتور را به «پایدار» تغییر می‌دهد.
- **تنظیمات ← آزمایش میکروفون**: سطح صدای زنده، پخش صدای ضبط‌شده، تبدیل آزمایشی به متن و آزمایش تشخیص سریع.
- پیام‌های خطا: رد شدن اجازه‌ی میکروفون / ضبط شدن سکوت مطلق (میکروفون اشتباه یا گرفته‌شده) / مسدود بودن شبکه (VPN یا سرور واسط) / نبودن کلید Gemini.
- در ایران حتماً یا VPN روشن باشد یا «سرور واسط» (پوشه‌ی `proxy/`) روی دامنه‌ی شخصی تنظیم شود.

## 🔊 صدای طبیعی (Gemini TTS و Gemini Live) — نسخه ۶
**هیچ‌جا به‌طور پیش‌فرض از صدای رباتیک گوشی (speechSynthesis) استفاده نمی‌شود.** اگر صدای Gemini در دسترس نباشد، متن نمایش داده می‌شود و پیام خطای فارسی می‌آید؛ پخش با صدای گوشی فقط با فعال کردن گزینه‌ی مربوط در تنظیمات (پیش‌فرض خاموش) ممکن است.

**مدل‌ها** (از مستندات ai.google.dev، اکتبر ۲۰۲۶):
- صدای درس‌ها و معلم: `gemini-3.8-flash-tts` از طریق Interactions API (`POST /v1beta/interactions`، خروجی WAV ۲۴ کیلوهرتز). گزینه‌ی ارزان‌تر `gemini-3.8-flash-lite-tts` سطح رایگان ندارد.
- معلم در «حالت صوتی بدون دست»: `gemini-3.8-live` (Live API، WebSocket؛ ورودی PCM ۱۶ کیلوهرتز، خروجی PCM ۲۴ کیلوهرتز، قطع کردن وسط حرف معلم). اگر Live وصل نشود، خودکار به حالت جایگزین می‌رود: ضبط صدا ← پاسخ متنی ← صدای Gemini TTS.

**ترتیب پیدا کردن صدای هر جمله‌ی درس:** ۱) فایل آماده در `audio/` (اگر ساخته شده باشد) ← ۲) حافظه‌ی IndexedDB دستگاه ← ۳) ساخت با Gemini TTS با کلید/سرور واسط کاربر و ذخیره برای دفعه‌های بعد (هر جمله فقط یک بار ساخته می‌شود). در گفتگوها هر شخصیت صدای خودش را دارد؛ «آهسته» با دستور سبک گفتار (`speaking slowly and clearly`) ساخته می‌شود، نه با کند کردن پخش.

**ساخت صداهای آماده هنگام build (پیشنهادی برای انتشار):**
```bash
node scripts/build.mjs                                   # اول محتوا ساخته شود
node scripts/gen-audio.mjs --dry                         # شمارش: حدود ۳۴۰۰ جمله / ۱۰۰ هزار کاراکتر
GEMINI_API_KEY=... node scripts/gen-audio.mjs            # خروجی: audio/*.mp3 + audio/manifest.json (قابل ادامه در صورت قطع)
node scripts/build.mjs                                   # audio/ را در dist/audio کپی می‌کند
```
گزینه‌ها: `--levels a1,a2` · `--format mp3|opus|wav` · `--concurrency 3` · `--limit N` · `--no-slow` · `--program no`. برای اجرا از ایران، VPN یا سرور خارج لازم است. هزینه‌ی تقریبی (قیمت پولی تا پایان ۲۰۲۶: ۹ دلار برای هر میلیون توکن صوتی، ۲۵ توکن در ثانیه): کل ~۳۴۰۰ جمله × ~۳ ثانیه ≈ ۲ تا ۳ دلار؛ با سطح رایگان هم ممکن است ولی محدودیت تعداد درخواست روزانه دارد. حجم mp3 حدود ۲۰ تا ۳۰ مگابایت. فایل‌های صوتی در precache سرویس‌ورکر نیستند و هنگام پخش در حافظه‌ی جداگانه (`zyaudio-1`) ذخیره می‌شوند.

**تنظیمات ← صدای طبیعی:** منبع صدا، صدای معلم (۱۶ صدای زن/مرد) با دکمه‌ی شنیدن نمونه، صدای راوی، مدل‌ها، روشن/خاموش Live، ساخت یک‌جای صدای همه‌ی جمله‌های سطح برای آفلاین، پاک کردن حافظه‌ی صدا.

**سرور واسط:** `proxy/` حالا مسیرهای TTS (`/v1beta/interactions`)، Live (WebSocket روی `/ws/...BidiGenerateContent`، کلید در سرور اضافه می‌شود) و توکن موقت (`POST /live-token`) را هم پشتیبانی می‌کند.

**هزینه/تأخیر:** Live حدود ۰٫۰۲۳ دلار در دقیقه گفتگو (پولی؛ سطح رایگان دارد). ساخت هر جمله با TTS معمولاً ۱ تا ۳ ثانیه طول می‌کشد (بار اول)؛ بعد از ذخیره فوری است. در گفتگوی پیوسته، جمله‌ی بعدی هم‌زمان با پخش جمله‌ی فعلی ساخته می‌شود.
