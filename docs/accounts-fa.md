# راه‌اندازی حساب کاربری و همگام‌سازی (Supabase — رایگان)

زبان‌یار بدون این مرحله هم کامل کار می‌کند (حالت مهمان، ذخیره روی همان دستگاه). برای ثبت‌نام/ورود و همگام‌سازی پیشرفت بین گوشی و کامپیوتر، یک بار این کارها را انجام دهید:

## چرا Supabase؟
- سطح رایگان: ۵۰٬۰۰۰ کاربر فعال ماهانه، ۵۰۰ مگابایت پایگاه‌داده، ۵ گیگابایت ترافیک، ۲ پروژه — برای این برنامه بیش از کافی.
- ثبت‌نام با ایمیل/رمز و پایگاه‌داده‌ی Postgres با «امنیت سطح سطر» (RLS)؛ بدون سرور اختصاصی و مناسب سایت ایستای GitHub Pages.
- Firebase متعلق به Google است و از ایران معمولاً تحریم/مسدود است. Supabase روی AWS است؛ دسترسی از ایران را نتوانستیم از اینجا آزمایش کنیم — اگر مسدود بود، برنامه در حالت آفلاین/مهمان ادامه می‌دهد و هر وقت وصل شد همگام می‌کند.
- ⚠️ پروژه‌ی رایگان پس از ۷ روز بی‌استفاده «Pause» می‌شود؛ با یک کلیک در داشبورد دوباره فعال می‌شود (داده‌ها حفظ می‌شوند).

## مراحل
1. در https://supabase.com با GitHub یا ایمیل حساب بسازید → **New project** → یک نام، رمز پایگاه‌داده و نزدیک‌ترین منطقه (مثلاً Frankfurt) را انتخاب کنید.
2. منوی **SQL Editor** → **New query** → محتوای فایل `supabase/migrations/001_zabanyar.sql` را کپی و **Run** کنید.
   - (اختیاری) برای «ورود با نام کاربری»، بخش ۵ آخر فایل را از حالت توضیح خارج کنید. نکته: با این کار هر کس نام کاربری را بداند می‌تواند ایمیل آن را بفهمد.
3. **Authentication → URL Configuration**: در *Site URL* آدرس سایت (مثلاً `https://USERNAME.github.io/zabanyar/`) و در *Redirect URLs* همان آدرس را بگذارید (برای لینک تأیید ایمیل و بازیابی رمز).
4. (اختیاری) **Authentication → Providers → Email**: اگر نمی‌خواهید کاربر ایمیل را تأیید کند، *Confirm email* را خاموش کنید (ثبت‌نام فوری). سرویس ایمیل رایگان Supabase محدودیت تعداد ارسال در ساعت دارد.
5. **Project Settings → API**: مقدار **Project URL** و کلید **anon public** را کپی کنید و در `config.js` (در ریشه‌ی سایت/پوشه‌ی `src`) بگذارید:
   ```js
   window.ZY_CONFIG = { supabaseUrl: "https://xxxx.supabase.co", supabaseAnonKey: "eyJhbGciOi..." };
   ```
   کلید anon عمومی است و انتشارش امن است چون RLS فعال است. **هرگز** کلید `service_role` را در برنامه نگذارید.
6. دوباره بسازید/منتشر کنید (`npm run build` یا جایگزین کردن `config.js` در `dist`). برای APK: `npx cap sync android` و ساخت دوباره.

(برای آزمایش بدون ساخت دوباره: تنظیمات ← حساب کاربری ← «تنظیم دستی سرور».)

## چه چیزی همگام می‌شود؟
درس‌ها و مراحل، کارت‌های مرور (SRS)، XP و روزهای پیاپی، برنامه‌ی روزانه، انتخاب دیالوگ‌ها و تنظیمات.
**کلیدهای API همگام نمی‌شوند** مگر خودتان در حساب ← «همگام‌سازی کلیدهای API» را با یک رمز جداگانه فعال کنید؛ در آن صورت کلیدها پیش از ارسال در مرورگر با AES-GCM رمزگذاری می‌شوند و سرور فقط متن رمزشده را می‌بیند.

## ادغام (آفلاین‌محور)
همه‌چیز اول روی دستگاه ذخیره می‌شود و چند ثانیه بعد از هر تغییر (و هنگام آنلاین شدن یا بستن برنامه) همگام می‌شود. درس‌های تمام‌شده از هر دو دستگاه جمع می‌شوند، برای هر کارت مرور نسخه‌ی جدیدتر می‌ماند، XP بیشینه‌ی دو طرف است و برای تنظیمات، نسخه‌ی جدیدتر برنده است.
